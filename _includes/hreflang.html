{% comment %} hreflang: the language alternates for a page that has a twin. Google drops a one-way set, so the self reference is emitted too; x-default always lands on the English page, the site default reading language. Pages without twin: in their front matter emit nothing at all. jekyll-sitemap emits no hreflang (checked its source), so these link tags are the only place the pairing is stated to crawlers. {% endcomment %} {% if page.twin %} {% assign self_lang = page.lang | default: site.locale %} {% assign twin_lang = 'zh-Hans' %}{% if self_lang == 'zh-Hans' %}{% assign twin_lang = 'en' %}{% endif %} {% endif %}
